# cstrike

My Counter-Strike settings: an autoexec file, a full game config and launch options.

A small project of my own from my Computer Science studies at UWM (2020–2024). The commit history is unchanged. This README was added in November 2026.

Years of work: 2024 (first and last commit on 6 May 2024).

## Contents

- `autoexec.cfg`: mouse and gameplay settings, for example `m_rawinput` and `zoom_sensitivity_ratio`.
- `config.cfg`: the full game configuration.
- `launch_opitons`: launch options, for example `-noforcemparms` and `-stretchaspect`.

## Running

The files need Counter-Strike, which this machine does not have, so I did not test them in November 2026.
